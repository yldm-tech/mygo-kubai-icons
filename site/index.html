Kubai Icons for MyGo brings the 2,901 icons of Kubai Icons to MyGo native UI in Go. A folder opens, an envelope unseals, a calendar turns to the next day: each icon moves on hover, and MyGo draws it itself, with no web view. Pick a colour, the soft look and a size, and copy the Go code. An unofficial port; the icons are MIT licensed.

go get github.com/yldm-tech/mygo-kubai-icons@latest
